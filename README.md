# Язык программирования Java  

Java — это широко используемый, объектно-ориентированный язык программирования высокого уровня и вычислительная платформа, выпущенная в 1995 году.  

__Характеристики:__   
_1. Объектно-ориентированное программирование (ООП):_  
Все программные компоненты — это объекты, что обеспечивает модульность и простоту поддержки. 

_2. Кроссплатформенность:_  
Код компилируется в байт-код, который работает на любой ОС, где установлена JVM. 
<!--JVM (Java Virtual Machine) — это виртуальная машина Java, ключевая часть платформы Java, 
которая исполняет скомпилированный байт-код на различных операционных системах -->

_3. Автоматическое управление памятью:_  
Наличие «сборщика мусора» (Garbage Collector) автоматически очищает память от неиспользуемых объектов.  

_4. Строгая типизация:_  
Переменные имеют жестко заданный тип, а операции проверяются на соответствие, что уменьшает количество ошибок. 

_5. Многопоточность:_  
Встроенная поддержка параллельного выполнения нескольких задач. 

_6. Безопасность:_  
Использование «песочницы» (sandbox) для ограничения доступа к ресурсам ОС и встроенные механизмы защиты. 

_7. Простота и надежность:_  
Синтаксис, схожий с C++, но упрощенный (нет явных указателей).  

_8. Динамичность:_  
Возможность адаптации к меняющимся условиям и динамическая загрузка классов.  

```java
public class HelloWorld {                
    public static void main(String[] args) { 
        System.out.println("Hello, World!"); 
    }                
}
```
<!--Имя класса = имя файла    
String[] args - массив строк,  который принимает аргументы, переданные программе при её запуске из командной строки  --> 


<!--_Статические_ языки проверяют типы данных при компиляции (до запуска), обеспечивая высокую надежность и производительность, а _динамические_ — во время выполнения,  
предлагая гибкость и скорость написания кода.  -->

<!-- Компилируемые языки — это языки, исходный код которых преобразуется компилятором в машинный код (бинарный файл), который затем может выполняться напрямую процессором. 
Компиляция происходит один раз до запуска программы, после чего полученный исполняемый файл можно запускать многократно.

Интерпретируемые языки — это языки, в которых исходный код выполняется методом интерпретации. 
Интерпретатор считывает и преобразует код в машинные инструкции в режиме реального времени, 
выполняя каждую инструкцию построчно-->
