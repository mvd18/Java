# Регулярные выражения  

Регулярные выражения (их еще называют regexp, или regex) - механизм поиска и замены текста. Лучше обычного поиска тем, что позволяет создать шаблон.

_Метасимволы и классы символов_ - заменяют собой конкретный диапазон значений  
| Символ | Значение |
|--------|----------|
| `.` | Любой символ, кроме перевода строки |
| `\d` | Цифра: `[0-9]` |
| `\D` | Не цифра: `[^0-9]` |
| `\w` | Символ слова: `[a-zA-Z0-9_]` |
| `\W` | Не символ слова: `[^a-zA-Z0-9_]` |
| `\s` | Пробельный символ |
| `\S` | Не пробельный символ |
| `[abc]` | Любой из перечисленных символов |
| `[^abc]` | Любой символ, кроме перечисленных |
| `[a-z]` | Диапазон символов | 

_Квантификаторы_ - так называют специальные символы в регулярных выражениях, которые указывают количество повторений текста
| Символ | Значение |
|--------|----------|
| `*` | 0 или более совпадений |
| `+` | 1 или более совпадений |
| `?` | 0 или 1 совпадение |
| `{n}` | Ровно n раз |
| `{n,}` | n или более раз |
| `{n,m}` | От n до m раз |

_Якоря и границы_ - не захватывают символы, а проверяют позицию в строке. Используются для точного ограничения области поиска 
и предотвращения частичных совпадений. Или метасимволы, обозначающие позицию строки.   
| Символ | Значение |
|--------|----------|
| `^` | Начало строки |
| `$` | Конец строки |
| `\b` | Граница слова |
| `\B` | Не граница слова |
| `\A` | Абсолютное начало строки |
| `\z` | Абсолютный конец строки |  

Oбратный слеш \ перед специальными символами(экранирование), чтобы воспринимались как часть поиска:  
`\. \* \+ \? \[ \] \( \) \{ \} \| \\ ^ $`
